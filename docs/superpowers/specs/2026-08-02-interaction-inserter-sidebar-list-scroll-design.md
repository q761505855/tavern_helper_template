# 互动插入器侧栏列表滚动设计

## 目标

角色数量或互动数量增加时，不再由角色面板持续撑高并挤占互动列表空间。角色列表与互动列表应在左侧栏内稳定共存，并分别滚动。

## 布局规则

- 顶部模式选择区域保持固定高度。
- 剩余高度由角色列表面板和互动列表面板以相同权重分配，默认比例为 `1:1`。
- 角色面板的标题和添加角色表单属于固定区域；角色条目区域使用剩余空间。
- 互动面板的标题属于固定区域；互动条目区域使用剩余空间。
- 两个面板的最小高度都应保证各自至少有一个条目的可视空间。
- 任一列表内容超出自身可视区域时，仅该列表出现纵向滚动，不改变另一面板的高度。
- 桌面侧栏与移动端抽屉采用相同的分配和滚动规则。
- 当可用高度低于两个面板最小高度与模式区域之和时，侧栏整体允许纵向滚动，确保控件不会被裁切。

## 实现边界

本次只调整 `src/interaction-inserter/App.vue` 中必要的语义类名，以及 `src/interaction-inserter/style.scss` 中的侧栏、面板和列表布局。角色、互动的数据结构和业务行为保持不变。

## 验证

- 添加多名角色后，角色条目区域出现纵向滚动，互动面板仍保留至少一个条目的高度。
- 创建多条互动后，互动条目区域独立滚动，角色面板高度不被挤占。
- 两边内容都较多时，两个面板默认等权占用可用高度。
- 桌面宽度和移动端抽屉下均满足上述行为。
- 极矮视口下可通过侧栏整体滚动访问所有区域。
