# Gemini 3 Flash 互动预设结构优化设计

## 目标

在不限制角色合理创作、权能和既定行为逻辑的前提下，降低互动回复中的固定演出感：连续括号、重复异象、擅自评价玩家、关系称呼膨胀、强制追问和每轮戏剧升级。

目标模型固定为 Gemini 3 Flash，不兼顾其他模型。

## 已确认的根因

1. 当前互动历史会把模型先前生成的回复再次送入上下文，错误句式容易自我强化。
2. 现有表达依据将“角色近期说过的话”放在最高优先级，模型生成的坏文本会被误当成角色标准口吻。
3. few-shot 位于角色卡、主剧情和互动历史之前，距离最终输入较远，容易被更近、更密集的文本模式覆盖。
4. 现有规则以抽象检查和禁止项为主，缺少与实际失败类型对应的正向示范。

## 方案比较

### 方案 A：只追加禁令

改动最小，但会继续增加提示词负担，也不能解决历史文本的示范效应。不采用。

### 方案 B：重排提示结构并重定义历史用途

将互动历史限定为事实和关系依据，明确模型先前生成的文本不是可靠文风样本；把 few-shot 移至互动历史之后，并加入高位非人角色的自然交流示例。改动集中在预设内部，不影响插件功能。采用。

### 方案 C：修改互动器代码过滤或压缩历史

能从数据层切断回音，但可能损失连续性，也扩大本轮范围。暂不采用；只有预设层优化仍无法控制时再考虑。

## 设计

### 表达依据

- 角色卡中的明确对白示例是可靠的表面表达依据。
- 角色设定决定行为、知识、关系和价值取向，但设定中的抽象形容词不直接扩写成重复旁白。
- 主剧情和互动记录主要提供事实、承诺、关系变化与当前状态。
- 模型先前生成的互动回复可用于连续性，不自动证明其句式、括号密度、称呼和互动模板正确。

### 回应强度

- 回应强度与玩家本轮行为匹配：定义问题先定义，纠错先纠错，选择题先给判断。
- 重大异象只服务于本轮真实发生的重大行动；普通说明不通过环境震颤、法则崩碎或身体接触增加分量。
- 角色可以温柔、忠诚、偏爱和强大，但主要通过实际判断、安排和措辞表现，不在台词、括号和旁白中重复标注。

### 历史防回音

- 在互动记录前后明确其用途是事实连续性，不是 few-shot。
- 要求发现近期回复存在重复结构时主动换用更适合本轮的结构。
- 不因上一轮以反问收尾、使用昵称或写了动作，就在下一轮继续复用。

### few-shot

- 保留通用角色示例，避免把固定世界观内容带入其他场景。
- 新增高位非人意识回答普通设定问题的示例。
- 新增角色承认前言说满并准确纠正的示例。
- 新增面对玩家“全都要”时落实方案、说明取舍而不戏剧升级的示例。
- few-shot 放在互动历史之后、生成前检查之前，以增强 Gemini 3 Flash 的近端模仿。

## 文件范围

- 修改 `tavern_sync/互动插入器预设/条目/` 内相关源条目。
- 修改 `tavern_sync/互动插入器预设/互动插入器预设.yaml` 的条目顺序。
- 使用项目既有 bundle 命令生成 `互动插入器预设.json`。
- 不修改互动器 TypeScript 代码。

## 验证

- bundle 命令成功。
- JSON 可解析。
- few-shot 位于互动历史之后、用户输入之前。
- 最终用户输入仍是最后一个启用项。
- 历史用途、回应强度和既往生成非风格依据等关键规则存在于生成 JSON。
- 不调用模型生成测试文本，由用户手动测试。
