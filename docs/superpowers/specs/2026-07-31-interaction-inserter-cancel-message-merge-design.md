# 互动插入器取消正文合并设计

## 目标

在互动工作台底部为“合并并退出”增加相邻的“取消合并”操作。该操作用于从当前最后一个聊天楼层的原始正文中删除互动插入器已经写入的全部上下文区块，并让相应互动记录能够再次合并。

## 交互

- “取消合并”按钮位于“合并并退出”左侧，仅在互动工作台视图显示。
- 点击后读取当前最后一个聊天楼层，不关闭工作台。
- 找到并删除内容时，提示本次删除的区块数量。
- 当前没有可操作楼层时，提示“当前没有可取消合并的楼层消息”。
- 当前楼层不存在匹配区块时，提示“当前楼层没有已合并的互动内容”，且不改变互动记录状态。

## 正文处理

- 匹配所有完整的 `<interaction_records_context>...</interaction_records_context>` 区块。
- 匹配跨行、非贪婪并执行全量替换，允许起始标签带属性及标签大小写变化。
- 不依赖区块内部的 `<records>` 结构，因此区块内部内容被手动修改后仍会被强制删除。
- 删除完成后只清理正文末尾遗留的空白，不改动其余正文内容。
- 使用 `setChatMessages` 更新原楼层，并刷新受影响的楼层显示。

## 互动记录状态

- 只有至少删除一个上下文区块且楼层更新成功后，才将聊天变量中所有 `merged: true` 的互动会话改为 `merged: false`。
- 状态改变后持久化聊天变量，使这些会话重新显示为“待合并”，并可再次参与“复制”或“合并并退出”。
- 不删除互动消息、角色列表或其他聊天变量。
- 不修改或清空世界书条目。

## 代码边界

- 在独立的纯函数中实现正文区块删除，返回清理后的正文和删除数量，便于直接测试多区块、手动修改区块和无匹配内容。
- store 操作负责读取楼层、调用纯函数、更新楼层、恢复会话状态和显示提示。
- Vue 组件只负责渲染按钮并调用 store 操作。

## 测试

- 纯函数删除一个区块并保留前面的原正文。
- 纯函数一次删除多个区块，包括内部被修改的区块。
- 无匹配区块时保持正文不变并返回删除数量 0。
- UI 测试确认按钮位于“合并并退出”左侧并绑定取消合并操作。
- store 行为测试确认成功路径更新当前楼层，并把已合并会话恢复为待合并。
