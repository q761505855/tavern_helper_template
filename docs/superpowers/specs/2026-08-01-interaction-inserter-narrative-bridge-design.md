# 互动插入器叙事过渡能力设计

## 目标

将互动插入器从以即时对话和简单现场互动为主的工具，扩展为楼层之间可连续游玩的补充叙事空间。

它必须保留原有的轻量互动能力，同时在玩家明确发起行动或要求展开剧情时，能够细致演绎战斗、展开当前剧情节点、探索合理转折，并让这些过程与结果被后续主剧情自然承接。

## 核心原则

### 按玩家意图调整叙事强度

- 普通闲聊、确认、追问、递物和简单动作仍采用简洁的即时回应，不自动制造大事件。
- 当玩家发起战斗、追逐、调查、谈判等连续行动，或明确要求展开某个剧情节点时，允许进行多阶段过程描写，不再受“只写短互动”或“即时回应后停止”的统一限制。
- 当玩家询问、试探或邀请剧情出现变化时，可以依据既有伏笔、人物动机、环境条件和世界逻辑引入合理的阻碍、发现、误会、反转或新机会。
- 篇幅、节奏和推进幅度由玩家输入与当前情境决定，不为了证明能够推进而无关加戏。

### 推进范围

互动插入器可以在合理情况下：

- 推进当前事件、人物关系和主线；
- 展开完整或阶段性的战斗、追逐、调查、谈判等过程；
- 引入有依据的新冲突、线索、发现、援助、阻碍或转折；
- 自然切换地点、推进时间；
- 形成胜负、伤势、消耗、位置变化、信息共享、承诺、关系变化等实际结果。

这些推进必须与角色能力、知识边界、人物动机、世界规则和已有事实一致。

### 玩家控制权

- 不替玩家编写未输入的台词、心理、感受、立场或关键决定。
- 可以描写其他角色、NPC、敌人和环境对玩家已声明行动的反应，也可以呈现这些反应造成的客观后果。
- 对玩家已明确发起的行动，可以演绎其合理过程；如果即将出现足以改变玩家立场、目标或命运的关键选择，应停在玩家能够回应的位置。
- 玩家没有明确要求一次演完时，不擅自替玩家跨过多个关键抉择。

## 场景模式

### 当下场景

保留多人知情、旁人插话、集体反应和角色互相接话的能力，同时承担现场事件展开与连续行动演绎。战斗等动态场景可以描写角色行动、敌方反应、环境变化、阶段性结果和新的局势，但应在关键选择点保留玩家控制权。

### 一对一

保留近距离私聊和即时反应，同时允许双方关系、冲突、合作和当前事件自然发展。角色可以主动采取符合其动机的行动，引出后续事件，或把私下互动推进到新的地点与时间；不能替玩家接受、拒绝或作出关键决定。

### 远程通信

保留通信媒介与知识边界，同时允许通信真实影响剧情。远端角色可以传递关键情报、调动合理资源、采取其权限内的行动、制造或解决局部问题，并在世界观支持时促成场景转换或后续事件。不能无视距离、媒介限制或角色权限直接解决一切。

## 提示词改动范围

修改以下源文件中的限制性表述，并用正向的叙事强度与推进规则替代：

- `tavern_sync/互动插入器预设/默认提示词配置.json`：重写三个模式提示词与互动记录合并模板。
- `tavern_sync/互动插入器预设/条目/✅互动插入器核心规则.txt`：更新定位、创作范围、连续性和响应边界。
- `tavern_sync/互动插入器预设/条目/📑使用说明.txt`：加入楼层过渡、战斗展开和转折探索用途。
- `tavern_sync/互动插入器预设/条目/💬对白质感.txt`：去除无条件阻止自然推进的表述，同时保留反客服腔和不过度拔高的要求。
- `tavern_sync/互动插入器预设/条目/😀情感基准.txt`：允许一轮完成多个连续且相关的行动阶段。
- `tavern_sync/互动插入器预设/条目/🛑后置约束.txt`：按玩家意图决定停止点，不再把“答完即停”作为统一规则。
- `tavern_sync/互动插入器预设/条目/🧠生成前检查.txt`：检查推进是否有依据、是否匹配玩家意图，以及是否保留关键选择权。
- `tavern_sync/互动插入器预设/条目/🧩模式协同规则.txt`：将“短互动边界”改为动态叙事尺度。

其他有关角色口吻、旁白人称、知识边界、格式清洁和不替玩家做决定的规则继续保留。

## 互动记录回流

互动记录合并回主楼层时，不再把所有内容都定义为轻量局部互动。后续主剧情应承认其中已经发生的过程与结果，包括：

- 战斗、追逐、调查和谈判的阶段或最终结果；
- 已发生的地点与时间变化；
- 新出现且符合设定的线索、转折、伤势、消耗和关系变化；
- 角色已经采取的行动、形成的承诺和共享的信息。

后续正文应吸收这些事实并从结果继续，不机械复述完整过程。若内容与更高优先级设定冲突，仍以更高优先级事实为准。

## 生成与验证

修改源提示词后，使用项目现有的 Tavern Sync bundle 命令重新生成 `互动插入器预设.json`。

验证包括：

- JSON 源配置能够正常解析；
- bundle 命令成功生成预设；
- 生成产物包含新的叙事定位、三个模式规则和回流策略；
- 源文件与生成产物中不再残留“不得推进主线、不得换场景、不得跳时、只能短互动”等无条件限制；
- 玩家控制权、角色知识边界和高优先级事实冲突处理仍然存在；
- 运行与互动插入器相关的现有测试，并检查最终差异。
